QUICK TEXT CHANGES
1. Open the .html file in Notepad (Windows) or TextEdit (Mac; choose Format > Make Plain Text).
2. Press Ctrl+F (Cmd+F on Mac) and search for the words you want to change.
3. Change only the words between the tags, for example:
      <p>Change this text</p>
   Never delete the < > tags themselves.
4. Save, then drag the WHOLE queenscoaching folder onto Netlify again (Deploys tab).
